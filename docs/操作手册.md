# 操作手册

## 管理员

1. 打开安装完成时保存的秘密入口，使用自己设置的管理员账号密码登录。
2. “邀请用户”中查找并选择已有 3x-ui 客户端，点击“生成邀请码”。无需另外填写门户账号，系统自动沿用客户端名称（email 标识，不要求是真实邮箱）。将邀请码或快捷邀请链接交给本人，有效 24 小时且只能兑换一次。
3. 未激活用户可“重发邀请”，旧邀请码、邀请链接及旧注册会话立即失效。已激活用户不能靠重发邀请覆盖密码。
4. 停用门户账号会撤销会话和本站中转权限，不会停用 3x-ui 节点或原站备用订阅。
5. 站点设置可修改名称、站长联系方式、面板 Token 与允许中转的来源。来源按每行 `协议://域名或IP:端口` 填写，不能包含路径；留空只允许面板同源。
6. HTTPS 区域查看证书到期时间、下次续期、最近结果；修改 DNS Token 后先保存，再申请。不要连续点击申请。只有 NAT 高端口时，为域名选择 DNS-01。
7. 自助重置默认关闭；先在授权的测试账号核实目标 3x-ui 版本，再开启。共享订阅、异常/过期/未激活状态、远端入站仍被拒绝。

面板地址安装后固定，防止同名客户端错绑。更换面板应规划绑定迁移，不能直接修改地址冒充同一资源。

## 普通用户

1. 登录页点击“首次使用？邀请码注册”，粘贴站长提供的邀请码，再点击“验证邀请码并继续”；也可打开邀请链接自动填入。首次不需要旧密码，必须在 10 分钟内设置本站密码。
2. 密码保存后直接进入首页；以后用客户端名称和本站密码登录。旧版本已经激活的账号继续使用原来的账号密码。首页显示到期/永久有效/未激活/禁用/流量耗尽状态及用量。数据每 15 秒同步，倒计时使用服务端时间校准。
3. 优先复制“本站中转”订阅链接；备用为原站直连。中转仍需要本站能访问原站，不是离线缓存，也不能解决原站完全不可用。
4. 更新订阅后在客户端手动刷新。本站与原站链接都属于访问凭据，勿公开。
5. 重置订阅需输入当前密码；会使旧订阅失效，但不会修改节点凭据。异常结果请联系站长，不要重复提交。
6. “账户安全”修改密码后所有会话退出。无法登录或激活过期时联系站长。

邀请码与邀请链接是同一份注册凭据，应私下交给对应用户，不要使用全站共用码。邀请码只授权首次注册，不能用于跳过已设置的密码。兑换限流为每 IP 每 15 分钟 20 次、全局每分钟 60 次；登录另外按 IP、账号和全局限流。限流是进程内固定窗口，重启会清空，多实例之间不共享；它降低暴力尝试风险，不代表绝对防爆破。

## 常见问题

- **首页 404**：这是设计行为；需访问正确秘密后缀。服务器管理员可只读查询门户 SQLite `SELECT suffix FROM site` 找回后缀，不要公开数据库。
- **浏览器证书错误**：核实主机/IP SAN、有效期及完整链。自签和测试 CA 证书不会自动受信任；不能把忽略证书错误当成正式部署方案。
- **面板连接失败**：检查 HTTP/HTTPS、端口、面板路径、API Token 权限及目标版本。HTTPS 保持证书校验；HTTP 仅在可信网络使用。
- **中转无入口**：核实订阅服务端口/域名已加入来源配置、subId 不共享、客户端归属一致。中转不跟随重定向。
- **重置待核实**：后台 rotations 表保留状态；先只读核对实际 subId 与节点同步结果，由管理员调查。不能删除记录后盲目重试。
- **证书申请失败**：HTTP-01 检查公网 80，DNS-01 检查目标 Zone 权限及传播，另检查 CA 限额。旧证书继续服务，后台显示安全错误摘要；至少一小时后重试。
- **管理员忘记密码**：当前无重置界面；从受限备份恢复或由具备权限的维护人员执行经过审核的恢复操作，不提供匿名后门。

反馈到 GitHub Issue 时附版本、复现步骤和脱敏错误。不要提交密码、Token、数据库、主密钥、完整订阅或邀请链接。
