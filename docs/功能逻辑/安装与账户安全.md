## 角色与入口

服务器操作者负责部署、HTTPS、数据目录和密钥权限。首次安装者须持有本机生成的随机安装凭证，在 `/install/凭证/` 填写站点名、登录后缀、管理员账号密码、面板完整地址及 admin API Token。登录后缀由用户设置，12–64 位字母、数字、下划线或连字符，可随机生成。

账号为 3–32 位允许字符；密码为 12–72 个 UTF-8 字节，首尾不得有空白。没有默认账号密码。前后端按同一字节限制校验。联系方式支持 HTTPS 或 mailto。

安装后的站长创建普通用户并选择面板客户端，生成一次性激活链接交给本人。用户首次免密码进入有限会话，必须自行设置本站密码后正常登录；不允许凭 email、subId 或客户端 ID 自行认领。详细流程见 [订阅中转与首次激活](订阅中转与首次激活.md)。管理员仍须在安装时设置密码。

## 初始化与持久化

`portal init` 显式生成 32 字节主密钥、独立 SQLite 模式和随机安装凭证。已有数据库但缺少主密钥时拒绝生成替代密钥。`portal serve` 要求数据库与前端发布产物已经存在，不自动建表或迁移。初始化 SQL 与顺序见 [SQL 说明](../sql/README.md)。

安装请求先只读验证面板查询 API，再在事务中保存站点和管理员。只有事务提交成功才切换为登录模式。安装后即使 setup.token 文件保留，安装路由也失效；并发安装由锁和数据库唯一约束保护。首次安装提交不自动登录。

数据库只保存门户账号、绑定与管理状态。bcrypt cost 12 保存密码哈希；AES-256-GCM 保存面板 Token，密钥存放在数据库目录外。会话随机凭证只以 SHA-256 摘要落库。备份必须包含匹配的数据库与主密钥。

## 登录与授权

根路径和错误后缀返回 404，不跳转泄露入口。常规登录要求账号密码；首次激活需要一次性邀请，不能空密码直接登录。登录前执行全局、来源和账号固定窗口限速。无效用户采用同成本密码比较，错误响应不区分不存在或密码错误。专用订阅中转 `/sub/签名凭证` 单独鉴权，不暴露秘密登录后缀。

会话有效期 12 小时，Cookie 限定后缀路径，设置 HttpOnly、SameSite=Strict，HTTPS 下设置 Secure。写请求校验配置的 Host/Origin 和 JSON；登录后的写请求另校验会话 CSRF Token。用户每次请求重新检查会话、角色及停用状态。

已激活用户改密码需要当前密码，并在事务中撤销所有会话。停用门户用户撤销会话及邀请，同时禁止本站订阅中转，不修改面板服务或原站备用链接。登录保存会话时再次核对密码哈希和启用状态，避免并发修改后签发旧凭据会话。

后端从登录用户读取绑定，用 email 定位后核对 ClientRecord ID。普通用户不能传入目标资源来更换绑定；管理员接口在后端检查角色。面板 API Token、密码哈希和完整面板客户端对象不透传普通用户。

## 接口与失败恢复

路径均相对当前秘密入口：安装期 `api/bootstrap`、`api/check`、`api/setup`；登录期 `api/bootstrap`、`api/login`、`api/activate`、`api/first-password`、`api/me`、`api/logout`、`api/password`。用户另有 `api/summary` 和 `api/rotate`；站长使用 `api/admin/users`、`clients`、`invite`、`user-state`、`settings`。

连接检查只读取面板客户端列表，不试写用户；表单值变化后旧检查结果不能表示新配置成功。最终安装再次验证连接。错误保留输入，不生成默认密码或降级认证。请求体限制 16 KiB、拒绝未知字段与多余 JSON。

首次安装失败可更正后重试；安装是否已完成以数据库状态为准。忘记后缀由服务器管理员从门户数据库或备份核实。首版没有管理员密码找回、用户密码重置或绑定修复界面，不提供匿名绕过入口。主密钥丢失只能恢复备份。

托管模式直接提供 HTTPS；代理模式仅监听回环。面板支持管理员配置的 HTTP 或 HTTPS。面板客户端不跟随重定向、不使用环境代理，不关闭证书验证。
