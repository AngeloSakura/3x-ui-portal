# 首版界面方向

Mode: Operate

## Direction contract

THESIS：让站长清楚知道装到哪一步，让用户一屏找到到期、用量和订阅动作；不依靠大屏监控式装饰制造复杂感。

OWN-WORLD：雾灰绿底、白色工作面、森林绿主操作；窄边框、系统中文字体、安静的留白和一致图标。

STORY：安装建立专属入口，验证面板，最后创建站点；登录进入按身份划分的工作区。

FIRST VIEWPORT：安装左侧 280px 步骤导航、右侧约 520px 表单；登录左侧简洁品牌与用途、右侧登录框。用户页左侧 224px 导航，右侧到期和用量明细，上方同步状态，订阅操作直接可见。390px 下表单单列，侧栏转顶栏。

FORM：直接基于已确认流程实现应用界面；seed: none (unavailable)。本次不启动技能的下载器、设计服务或构建流程。

FINISH：完成代码与静态检查，记录实际验证边界；渲染及运行验收待在获准环境完成，不能以静态预览代替功能验收。

## 订阅中转与首次激活扩展

沿用现有任务界面，不更换视觉风格。订阅区按每种格式展示主用中转与原站备用，主用实心按钮、备用普通按钮；中转来源未配置时明确说明并禁用主用复制。长地址独立滚动，手机上下排列。

站长创建用户移除初始密码字段，成功后显示可复制的一次性邀请及有效期；待激活用户提供重发确认。用户打开邀请后主动验证，进入单列表单设置密码，无跳过入口；完成后正常登录。未做浏览器视觉验收。
