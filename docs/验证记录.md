## NAT 部署实测

测试环境为 64 MiB Alpine / OpenRC 容器，站点使用映射高端口；服务器标识、凭据和秘密入口不公开。

- 安装器从 GitHub Release 下载并校验安装包，初始化独立数据库，使用 portal-svc 账号运行，加入 OpenRC default 运行级别。
- 使用 7 天自签测试证书；通过已固定主机密钥的 SSH 通道取得证书后，本地 HTTPS 客户端信任该证书完成公网请求验证。浏览器测试明确允许本次测试证书，未视作公网 CA 签发成功。
- 公网浏览器验证安装页面、桌面/手机布局、明暗切换与刷新后保持、作者主页；根路径及错误安装凭证返回 404，没有页面脚本错误。
- 实际执行服务重启并恢复访问；主密钥、安装凭证和加密证书状态文件校验值保持一致，服务重启后 RSS 约 17 MiB。不是容量或并发测试，建议正式部署至少 128 MiB。
- 部署前安装额外运行时曾触发容器内存限制；安装器已去掉 Python 依赖。发行安装及浏览器验证期间 OOM 计数未增加。
- 保留首次设置状态，未创建默认管理员、未填入真实面板密钥。首次设置入口仅保存在私密交付文件，不提交仓库。
- 域名证书测试按用户要求延后。当前没有公网 80/443，未进行可信 IP 证书申请。
