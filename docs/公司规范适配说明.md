# 公司规范适配说明

适配日期：2026-11-09。依据用户提供的公司 `AGENTS.md`，为独立 3x-ui 用户端裁剪；原附件、机器级技能及 3x-ui 源码均不修改。

## 保留

- 默认禁止构建/编译、Git 操作；先检查脚本，串行轻量校验，不临时安装依赖或启动服务。
- 数据库与环境边界、生产变更只交 SQL、避免接口和 ORM 间接写库。
- 完整业务链路自查、如实披露未验证项、功能逻辑文档与 SQL 记录。
- 职责解耦、重复逻辑评估、中文解释性注释、统一授权、正常用户操作习惯及性能边界。
- 本地技能优先、完整读取、适配审查和关键技能交付说明。

## 删除或替换

| 原条目 | 本项目处理与原因 |

## 为本项目补充

面板与用户端部署隔离、服务端凭据保护、账号绑定防越权、API 版本能力识别、到期时间单位与未激活状态、共享订阅归属、重置的副作用及读回、同步失败展示。
